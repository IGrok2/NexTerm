# NexTerm 0.2 — merged edition

- Uses `pyte` as the terminal engine and a standard Qt text component for rendering.
- Added mouse selection, clipboard actions, ANSI colors, function keys and PTY resize.
- Rebuilt SFTP as an integrated dual-pane workspace with a transfer queue.
- Added recursive folder transfers, progress, rename, mkdir and safe local deletion.
- Added first-connect SSH fingerprint verification and persistent known hosts.
- Kept groups, favorites, search, OpenSSH import, snippets, logs and port forwarding.
- Moved secrets to Windows Credential Manager instead of a decryptable local key file.
- Added Windows 11 theme controls, Mica, accent colors and terminal personalization.
- Added a Windows launcher and PyInstaller build script.
